# Archive (Arşivlenmiş Dosyalar)

Bu dizin, projenin erken aşamalarından kalma, artık üretim veya test süreçlerinde kullanılmayan legacy bileşenleri barındırır:

- **`legacy-python-api/`**: Projenin ilk aşamasında geliştirilen FastAPI (Python 3.12) prototipi. Sistem AWS Lambda (Node.js 22 ARM64) ve Clean Architecture TypeScript mikroservislerine (`services/*`) taşındığı için tarihsel referans amacıyla arşivlenmiştir.
- **`.agent-advisor/`**: Erken dönem agent oturum kayıtları ve geçici analiz dosyaları.
