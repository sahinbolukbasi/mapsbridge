# Stitch UI Tasarım Şablonları (Mockups)

Bu dizin, MapsBridge platformu için Stitch MCP aracı kullanılarak üretilmiş görsel arayüz şablonlarını (`stitch-mockups/`) içerir:
- HTML önizleme sayfaları
- PNG yüksek çözünürlüklü tasarım ekran görüntüleri

Bu tasarımlar `packages/ui` (`@mapsbridge/ui`) içindeki CSS token'ları ve `apps/web/` arayüz bileşenleri için referans teşkil eder.
